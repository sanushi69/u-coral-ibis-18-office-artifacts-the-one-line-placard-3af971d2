## The entry

`main.py` writes one line — a museum placard for an ordinary office object, written as if the object were an ancient artifact — to `/output/entry.txt`:

> Mug, c. 2011. Chipped ceramic. Inscribed 'World's Best Boss' in a hand no scholar has identified; the claim was never challenged. Gift of the leaving party.

156 characters, one line. The joke treats the mug's boast as an archaeological inscription: a claim no scholar can attribute and nobody ever challenged.

## Run

```sh
python3 main.py
```
